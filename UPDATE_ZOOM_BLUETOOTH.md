# Update StopMotion Pro

## Perubahan
- Editor Erase memiliki kontrol Zoom − / + dari 100% sampai 400%, serta Reset.
- Tombol Volume Up dan Volume Down dari remote/tripod Bluetooth ditangani sebagai shutter ketika layar kamera StopMotion Pro sedang aktif.
- Di luar layar kamera, tombol volume tetap berfungsi normal.

## Catatan
Build belum dapat diverifikasi di lingkungan ini karena Gradle/Gradle Wrapper tidak tersedia. Buka proyek di Android Studio dan jalankan Sync/Build sebelum memasang APK.
